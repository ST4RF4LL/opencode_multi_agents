BOUNDARIES

平台安全边界

  • 服务仅监听 localhost / 127.0.0.1 / [::1]。
  • 审计项目由操作员指定工作台所在机器上的绝对目录，并在服务端规范化、校验和持久登记。
  • 目标源码目录与工作台 OpenCode Agent/MCP 配置相互隔离。
  • OpenCode 通过参数数组与固定 orchestrator prompt 启动，shell=false。
  • 默认拒绝脏工作树和未 checkout 的目标 ref。
  • 测试环境 ENABLE 是 120 秒快速动态的任务级显式授权；完整动态仍需逐次人工授权，两者都只允许 loopback。

NEW AUDIT

创建仓库级安全审计

测试目标补充说明追加当前任务要求与关注重点，例如“只验证 XSS 漏洞”。
测试环境信息松散填写 URL、测试账号、密码、登录方式及其他环境说明。

未启用或未填写时，主审计不会启动浏览器，所有初步支持项直接进入本地三方静态复核。启用即明确授权审计主链执行一次、全任务最多 120 秒的 loopback 快速动态确认；信息按敏感上下文保存且不在任务 API 中回显。完整动态验证资格不受此开关限制，可在验证页补录环境并逐次授权。

AUDIT TARGET

指定审计项目目录

这里填写工作台服务所在 macOS、WSL、Windows 或 Linux 主机可访问的绝对目录。浏览器安全模型无法返回本机绝对路径，因此使用明确的路径输入。

REMOVE AUDIT TARGET

删除审计项目

将从工作台移除项目 （）的登记信息。源码目录和磁盘文件不会被删除；存在关联审计时必须先删除审计任务。

DELETE AUDIT

删除审计任务

将删除任务 在工作台中的运行状态、可归属报告、临时文件、执行工作区以及关联验证/处置状态。被审计源码目录不会被修改。

LOCALHOST VALIDATION

授权动态验证

账号信息为可选：全部留空表示匿名验证；只填一组或填写同一账号表示共享账号验证；填写两个不同账号才允许形成跨用户证据。

Web XSS、身份隔离或持久化操作会自动升级到独立临时 Chrome，不能降级；低影响验证可使用现有 Chrome 的任务独立标签页。凭证只传给本次 OpenCode 会话，日志和持久制品不得保存凭证值。

STOP VALIDATION

停止动态验证

将停止验证 。只终止该验证任务并关闭它创建的浏览器会话；不会终止其他 Chrome 进程，也不会删除已有审计制品。
